## Installation
1. Download theme.json
2. Go to the settings in Somtoday
3. Go to Mod-settings
4. Scroll all the way down until you find "Export mod settings" and "Import mod settings"
5. Click on "Import mod settings"
6. Select the downloaded theme.json
7. Scroll back up and select "Save settings"
